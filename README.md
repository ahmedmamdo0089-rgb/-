# 🏛️ بنك الحظ المصري (Egyptian Monopoly Multiplayer)

لعبة ويب تفاعلية جماعية متكاملة باللغة العربية تحاكي لعبة **"بنك الحظ" (Monopoly)** بنسخة مصرية عصرية، مع نظام غرف أونلاين لحظي عبر **WebSockets (`Node.js` + `Express` + `Socket.io`)** وروابط دعوة فورية للأصدقاء.

---

## ✨ المميزات الرئيسية

1. **واجهة عربية كاملة (RTL):** جميع القوائم، البطاقات، الرسائل، الدردشة، وسجل الأحداث مصممة باللغة العربية وبخطوط عربية عصرية (`Cairo` و `Tajawal`).
2. **خريطة مصر التفاعلية (40 خانة قياسية):**
   - **22 محافظة ومدينة مصرية** مقسمة إلى 8 مجموعات لونية متدرجة الأسعار منطقياً من شمال الصعيد (`الفيوم` و`بني سويف` بـ `600 ج.م`) مروراً بمدن القناة والدلتا والبحر الأحمر والأقصر وأسوان والجيزة، وصولاً إلى الأغلى سعراً: **`الإسكندرية` (`3,500 ج.م`) و`القاهرة` (`4,000 ج.م`)**.
   - **4 محطات نقل رئيسية:** `محطة مصر (رمسيس)`، `مترو الأنفاق`، `ميناء الإسكندرية`، و`مطار القاهرة الدولي`.
   - **مرفقان عامان:** `شركة الكهرباء` ⚡ و`شركة المياه` 💧.
3. **بطاقات ثقافية مصرية ممتعة:**
   - **16 بطاقة مفاجأة (فرصة 🎁)** و**16 بطاقة صندوق المحكمة (⚖️)** بأحداث مصرية طريفة وواقعية (فوازير رمضان، زحمة كوبري أكتوبر، رادار الدائري، نقطة الفرح، خان الخليلي، التصالح العقاري، بطاقات العفو للخروج من السجن، إلخ).
4. **نظام اللعب الجماعي وروابط الدعوة (`Socket.io`):**
   - إنشاء غرف خاصة من **لاعبين اثنين (2) كحد أدنى وحتى (6) لاعبين كحد أقصى**.
   - توليد **رابط دعوة فريد (`?room=XXXXXX`)** لكل غرفة مع زر نسخ فوري وزر مشاركة مباشر عبر **واتساب** لإرساله في الجروبات.
   - إعادة اتصال تلقائية (`Session Reconnection`) في حال تحديث الصفحة على الهاتف المحمول، وإمكانية إضافة لاعبين آليين (`🤖 بوت ذكي`).
5. **قواعد لعب متكاملة:**
   - شراء الأراضي، احتكار المجموعات اللونية (مضاعفة الإيجار)، البناء المتساوي للمنازل (حتى 4 منازل 🏠) وتشييد الفنادق السياحية (🏨).
   - نظام الرهن العقاري وفك الرهن لتدبير السيولة.
   - **نظام مقايضة متكامل (Trade):** تبادل المحافظات والأموال وبطاقات الخروج من السجن بين اللاعبين في الوقت الفعلي.
   - **نظام تسوية الديون والإفلاس:** تنبيه اللاعب عند نقص السيولة لبيع المباني أو رهن العقارات أو المقايضة قبل إعلان الإفلاس رسمياً وتتويج الفائز الأخير.
6. **تصميم متجاوب وأنيميشن حديث:**
   - **نرد ثلاثي الأبعاد (3D CSS Cubes)** وحركة سلسة لقطع اللاعبين خطوة بخطوة حول الخريطة مع مؤثرات صوتية تفاعلية (`Web Audio API`).
   - متوافق بالكامل مع متصفحات **أندرويد (Android)** وشاشات الكمبيوتر، مع شريط تنقل سفلي للهواتف وخيار تكبير الخريطة (`🔍 تكبير`).

## 🚀 طريقة التشغيل (اللعب الجماعي عبر Node.js و Socket.io)

### 1. المتطلبات
تأكد من تثبيت **[Node.js](https://nodejs.org/)** (الإصدار 18 أو أحدث) على جهازك.

### 2. تثبيت الحزم وتشغيل الخادم
افتح موجه الأوامر (`Terminal` أو `PowerShell`) داخل مجلد المشروع ونفّذ:

```bash
npm install
npm start
```

سيعمل الخادم فوراً على المنفذ `3000`:
- على جهاز الكمبيوتر: افتح `http://localhost:3000`
- على الهواتف المتصلة بنفس شبكة الـ Wi-Fi: سيطبع لك الخادم رابط الشبكة تلقائياً مثل `http://192.168.1.X:3000`
- للعب عبر الإنترنت من أي مكان: ارفع المشروع مجاناً على **Render** أو **Railway** أو **Glitch** (أمر البناء `npm install` وأمر التشغيل `npm start`) وشارك رابط الغرفة مع أصدقائك!

### 💡 وضع المعاينة السريعة بدون خادم
حتى قبل تثبيت `Node.js`، يمكنك فتح الملف `public/index.html` مباشرةً في المتصفح لتجربة اللعبة فوراً مع اللاعبين الآليين (`🤖`) أو عبر عدة تبويبات في نفس المتصفح!
